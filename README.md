# atividade--6
O Git é um sistema de controle de versão distribuído que rastreia alterações no código, permitindo salvar o histórico do projeto, reverter a estados anteriores e facilitar a colaboração entre desenvolvedores. Suas principais funções incluem gerenciamento de branches (ramos) para trabalho paralelo, commits para salvar versões, e fusão de código (merge)
O GitHub é a maior plataforma de hospedagem de código-fonte do mundo, funcionando como uma "rede social" para desenvolvedores e uma ferramenta essencial para o trabalho colaborativo. Suas principais funções giram em torno do uso do sistema de controle de versão Git para armazenar e gerenciar projetos na nuvem.
1. Preparação (Antes de subir)Criar conta: Acesse github.com e crie sua conta.Instalar o Git: Se for usar o terminal, baixe e instale o Git em seu computador.Configurar o Git: Abra seu terminal e defina seu nome e e-mail com os comandos:bashgit config --global user.name "Seu Nome"
git config --global user.email "seuemail@exemplo.com"
Use o código com cuidado.
2. Criar o Repositório no GitHubNo canto superior direito, clique no ícone + e selecione "New repository".Dê um nome ao seu projeto. Adicione uma descrição (opcional).Deixe o repositório como Público para que outros vejam.Opcional: Marque "Add a README file" para descrever seu projeto.Clique em "Create repository".
3. Subir o Projeto (Método 1: Interface do Site - Mais Fácil)Ideal para projetos pequenos (apenas arquivos soltos).Na página do repositório que você acabou de criar, clique em "uploading an existing file".Arraste e solte os arquivos do seu projeto do computador para o navegador. No final da página, adicione uma mensagem de commit (ex: "Primeiro commit") e clique em "Commit changes".
4. Subir o Projeto (Método 2: Terminal/Linha de Comando - Recomendado)Ideal para projetos completos com pastas e subpastas.Abra o terminal/Git Bash na pasta do seu projeto local.Inicialize o Git: git initAdicione os arquivos: git add . (o . adiciona tudo)Faça o commit: git commit -m "meu primeiro projeto"Conecte ao GitHub: Use o comando fornecido pelo GitHub na página do repositório (parecido com isto):git remote add origin https://github.comRenomeie a branch (opcional, mas recomendado): git branch -M mainSuba o projeto: git push -u origin main .Este vídeo demonstra o passo a passo de como subir seu projeto usando a linha de comando:54sComo Subir Projeto.
5.  Como postar o site no ar (GitHub Pages)Se o seu projeto for um site simples (HTML/CSS/JS), você pode hospedá-lo gratuitamente:No seu repositório, vá em Settings (Configurações).No menu esquerdo, clique em Pages.Em "Source", selecione a branch main e a pasta /(root).
6.  clique em Save.
